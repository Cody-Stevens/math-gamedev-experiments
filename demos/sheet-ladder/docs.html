Sheet kit 1.1

HTML elements for sheets people review: layout, charts, media, live controls, reader replies and 3D. One file, two kit links, no build step and no network.

Version 1.1.2 · riso by default, riso-night, eight flair pieces · manifest.json lists every element, attribute and chart type

Start a sheet

  1. Link the pinned kit: one stylesheet, one deferred script.
  2. Pick a theme on body and write tk-* elements; data goes in application/json scripts.
  3. Run tacksheet.py sheet validate, then tack the file with interactive: true.

The kit exposes Tacksheet.state, Tacksheet.on(), Tacksheet.chart() and Tacksheet.define() for your own code, and every colour, face and radius is a CSS custom property you can override.

<link rel="stylesheet" href="https://tacksheet.com/kit/1.1.2/tacksheet.css">
<script src="https://tacksheet.com/kit/1.1.2/tacksheet.js" defer></script>
<body data-tk-theme="riso">
<tk-page>
  <tk-hero><tk-tape-title tape="kraft"><h1>Q3 ridership</h1></tk-tape-title></tk-hero>
  <tk-chart type="bar" data="#trips" title="Trips per month"></tk-chart>
</tk-page>
<script type="application/json" id="trips">
{"labels":["Jul","Aug","Sep"],"datasets":[{"label":"Trips","data":[61.8,63.9,58.6]}]}
</script>
</body>

Themes

Riso is the default: a body without data-tk-theme prints in two inks on riso stock. riso-night is the same printing on deep navy stock, and auto moves between the two with the reader’s system. In both riso themes the page column sits on a translucent reading panel, so type stays crisp over the texture (--tk-panel:transparent turns it off). The other looks stay for sheets that need them. Each has its own type, rules and colour-blind-safe chart palette. Pick one to restyle this whole page, charts and 3D included. Override any token (--tk-accent, --tk-font-head, --tk-radius, --tk-texture…) to make a sheet your own.

Examples

Eleven finished sheets ship with the kit's source in examples/sheets/, and between them they use every element. Each is a pattern worth copying whole. tacksheet.py sheet new --template NAME OUT.html copies one, pinned to this kit, with the files it uses.

    Charts

    One element, <tk-chart type data x y series>, and forty-nine types on a single mark system: thin lines with ringed markers, bars with a rounded data end, hairline grids, labels in text colours and a legend only for two or more series. Every chart carries a data table behind “View data”. The options attribute deep-merges raw ECharts JSON for anything else.

    Reader replies

    Every widget talks to the shell over the tacksheet-sheet-v1 bridge. Opened anywhere else they render disabled with “Open this sheet in Tacksheet to reply”, which is what you see here.

    Riso flair

    Paper, tape and ink pieces that make a sheet look printed and pinned rather than generated. They work on every theme and look most at home on riso and riso-night. Each is one element with a few attributes, no network and no images of its own beyond the kit's textures.

    Compose like a pinned, printed sheet

    • Print in one or two inks and keep them: cobalt for type, vermilion for marks, plum where they overprint. Sunflower and cornflower are the night stock's inks.
    • Tape the title and the images. Leave charts, tables and cards flat on the stock; one taped thing per screen is plenty.
    • Stamp a state once, next to what it describes. Put a slip beside the paragraph it answers, not in a sidebar.
    • Highlight a phrase, not a paragraph. Use a torn strip to change subject, not between every section.
    • Avoid generic gradients, glass, glows and rows of identical rounded cards. Texture is the point, and legibility comes first: the kit checks tape-title contrast for you, and every other piece keeps the page's text colours.

    tk-tape-title

    A real heading printed on washi tape: translucent film with torn ends, fibre and a faint pattern, each line on its own strip. The kit measures the tape as it lands on the page and prints the title in an ink that clears 4.5:1 (3:1 at 24px and up). An ink that fails is replaced by cobalt, near-black or cream, with a console warning; if none clears a patterned film, the film prints solid. The last title below asks for black on cobalt and gets cream.

    level: 1 | 2 | 3 · tape: kraft | frost | vermilion | cobalt | plum | sunflower | cornflower | blush · pattern: plain | grid | dots | stripes | kraft · ink: auto | cobalt | black | cream | vermilion | plum · tilt · hand

    tk-taped

    Tapes its content to the sheet. An image becomes a print with a cream border (it stays cream on night stock); anything else is taped as it is with frame="none". A caption is handwritten on the print.

    tk-stamp

    A rubber stamp in one ink, worn by the pad and struck at an angle (it thumps in once, unless the reader prefers reduced motion). Preset words carry their own ink; your own word goes inside. Screen readers hear "Approved stamp, 3 Oct 2026".

    kind: approved | draft | rejected | final | shared | seen · ink: cobalt | vermilion | plum · shape: box | double | round · date · tilt

    tk-duotone

    Prints an image in two inks on cream paper: the first carries the shadows, the second lands a little off register over the midtones and overprints where they meet. halftone screens the second ink into dots. Give the image its alt text as usual.

    Display words or numbers printed twice, the second pass off register. Named inks switch to their night shades on riso-night. Screen readers read the words once.

    Your own code

    Agents may add their own CSS, scripts and custom elements alongside the kit. Build DOM with createElement and textContent, read the tokens in CSS, and use the API below. See examples/sheets/custom-component.html for a full component.

    • Tacksheet.state.get(name) / set(name, v) / all()Read and write named state; every bound element updates.
    • Tacksheet.on('change', fn)Called with {name, value, values} after every state change. Also 'theme'.
    • Tacksheet.chart(node)Re-render one tk-chart after you change its data block.
    • Tacksheet.theme()The resolved theme: palette, colours, faces and 3D tokens.
    • Tacksheet.file(name)A Promise of a same-review file as a Blob, through the bridge.
    • Tacksheet.expr(text)The safe expression evaluator used by filters and templates.
    • Tacksheet.define(name, class)Register a custom element once, after the kit is ready.
    • Tacksheet.readyA Promise that resolves when the document is parsed.

    Bridge protocol

    Sheets run in an opaque-origin sandbox, so messages arrive with origin "null": the shell checks event.source, and so does the sheet. Every message carries both kind and type. The kit always sends resize so the shell can size the frame.

    Sheets cannot fetch (connect-src 'none'), so same-review files (./files/…) arrive through file.fetch: the kit asks by bare name, the shell transfers the ArrayBuffer, and the kit turns it into a blob: URL for media or parses it for tk-model.

    Manifest and agent prompt

    manifest.json lists every element, attribute, chart type and data shape, theme, file hash and bridge message. The recommended agent prompt:

    Build a Tacksheet sheet: one HTML file with
<link rel="stylesheet" href="https://tacksheet.com/kit/1.1.2/tacksheet.css"> and
<script src="https://tacksheet.com/kit/1.1.2/tacksheet.js" defer></script>,
body data-tk-theme="riso" (riso-night for dark stock, auto to follow the
reader; paper, ink and slate also work). Use tk-* elements (see the
manifest for names and attributes), inline data as
application/json scripts, and validate with `tacksheet.py sheet validate`
before publishing. Long-form rows need series="..." (see long-data.html).
Put sparklines inside tk-stat. Load sibling files as src="./files/<name>"
(the file.fetch bridge); models under ~1 MB can ride inline as glb="..."
or glb="#id". Drive scrolly with <tk-scrolly for="<chart-id>"> plus one
JSON {"filter": "..."} per step, cumulative (n <= 3, n <= 6, ...). Custom
components go through Tacksheet.define (see custom-component.html).
Compose like a pinned, printed sheet: one or two inks, a tk-tape-title for
the title, tk-taped for images, a tk-stamp for a state, a tk-slip for an
aside; no generic gradients or rows of identical cards.
